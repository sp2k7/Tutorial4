This repository was created for Tutorial 4 to practice using Git and GitHub for version control and collaboration.

## Purpose
To demonstrate the full Git workflow by:
- Initializing a local repository
- Creating and pushing branches
- Collaborating with a peer via GitHub
- Submitting and merging a pull request

## What’s Included?
- `name.py`: A Python file that prompts the user to enter their first and last name, then prints the full name.

## Steps Completed
1. Installed Git and created a GitHub account
2. Created this public repository
3. Added a collaborator to the repository
4. Created a new branch with the name `python`
5. Added and committed `name.py`
6. Pushed the branch to GitHub
7. Created a pull request and assigned the collaborator as reviewer
8. Pull request was approved and merged into `main`
